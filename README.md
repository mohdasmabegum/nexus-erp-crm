# Nexus ERP CRM


Mini ERP + CRM Operations Portal

## Tech Stack

### Backend

- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication

### Frontend

- React
- Vite
- TypeScript
- Material UI

## Modules

- Authentication
- Customer CRM
- Products
- Inventory
- Sales Challans

## Run

Backend

```bash
cd server
npm install
npm run dev
```

Frontend

```bash
cd client
npm install
npm run dev
```

Database

```bash
docker compose up -d
```
